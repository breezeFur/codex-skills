# 项目市场调研工作流参考

本参考对应当前项目的 `market-research-v6-cache-insights` 工作流。它描述 Agent 侧应遵守的业务边界，不替代 MCP 工具的实时 schema。

## 三阶段编排

```text
screeningGraph
  -> productSelectionGate
  -> deepDiveGraph
  -> finalAnalysisGraph
  -> finalizeArtifacts
```

阶段一完成后进入 `WAITING_INPUT`。用户选择 `ENTER` 才进入商品深挖；用户选择 `ABANDON` 则结束市场初筛。Agent 不应把自动排序当成用户授权。

## 阶段一证据

| 证据表 | 主要数据 | 分析问题 |
| --- | --- | --- |
| US | 产品研究结果 | 市场中有哪些候选商品，规模、价格、评分、卖家和内容配置如何 |
| 行业销售趋势 | 多月市场统计 | 市场销量、销售额、价格、BSR、品牌和卖家是否增长或波动 |
| 行业需求及趋势 | 市场需求趋势、关键词趋势 | 搜索/购买需求和供需信号是否改善 |
| 细分市场现状 | 市场研究、统计、价格、上架、内容和卖家分布 | 子市场的规模、结构、进入门槛和机会 |
| 细分市场退货率 | 需求/统计结果中的退货字段 | 退货信号相对类目均值的风险等级 |
| 竞品品牌 | 品牌集中度 | 品牌份额、代表 ASIN、产品线和集中度 |
| 商品集中度 | 商品、品牌/卖家及累计份额 | 头部商品是否垄断、长尾是否存在空间 |

行业销售趋势通常需要对多个历史月份分别调用 `sellersprite_get_market_statistics`，再按月份确定性聚合；不要把单月响应命名为趋势。

## 阶段二证据

| 证据表 | 主要数据 | 分析问题 |
| --- | --- | --- |
| 评价 | `sellersprite_list_reviews` | 用户具体喜欢什么、抱怨什么，评论样本有什么边界 |
| VOC | 评论的确定性聚合 | 正负向主题、星级、VP、图片/视频和赞同信号 |
| Keywords | 关键词研究、挖掘、ASIN 流量词 | 搜索需求、竞争强度、自然/广告排名和获客难度 |
| ASIN销售趋势 | `sellersprite_get_asin_sales_trend` | 样本商品销量、销售额、价格及波动 |
| ASIN运营趋势 | `sellersprite_get_keepa_trend` | 样本商品的经营指标变化和稳定性 |

## 最终报告约束

最终报告按照 12 张证据表顺序输出，每章解释证据对决策的影响，不重复粘贴完整原始表。报告中应区分市场级证据与样本 ASIN 证据，保留数据时间和样本边界。

项目的正式后端还会持久化数据集、事件和 Excel/PDF 产物；本 Skill 只通过 MCP 获取数据并在 Agent 会话中分析，除非环境额外暴露项目工作流工具。
