# 项目市场调研工作流与 12 证据表规范 (Project Workflow)

本参考规范对应 `market-research-v6-cache-insights` 工作流及 12 张不可变证据表。

---

## 阶段一：7 张市场初筛证据表

| 证据表 | 核心数据 | 业务分析核心问题 |
| :--- | :--- | :--- |
| **US / 候选商品** | Top100 商品榜单 | 市场头部商品的价格区间、评分数、月销量、留评率、上架时间 |
| **行业销售趋势** | 多月份市场统计 | 行业月总销量/销售额是否处于增长通道，均价是否有上移趋势，淡旺季波幅 |
| **行业需求及趋势** | 关键词搜索量与需求走势 | 核心大词年同比增速、购买率、供需比（搜索量/商品数） |
| **细分市场现状** | 细分节点整体概况 | 细分赛道商品体量、卖家数、A+普及率、Amazon 自营渠道占比 |
| **细分市场退货率** | 细分节点退货率 vs 类目均值 | 退货率差值是否高危（高于大盘均值 3% 以上为预警线） |
| **竞品品牌** | 品牌集中度数据 | CR3 / CR10 品牌份额，是否存在寡头垄断，长尾品牌生存空间 |
| **商品集中度** | 商品与卖家集中度 | Top 10 商品销量占大盘的百分比，是否存在单一超级爆款压制 |

## 阶段二：5 张标杆深挖证据表

| 证据表 | 核心数据 | 业务分析核心问题 |
| :--- | :--- | :--- |
| **评价列表** | 真实买家 1~3 星差评与 4~5 星好评 | 买家第一手原声：故障部位、材质抱怨、包装吐槽、惊喜卖点 |
| **VOC 痛点画像** | 差评聚类与未满足需求分析 | 痛点发生频次排序、严重等级、对标差评转化为我方设计路线图 |
| **Keywords** | 流量词反查与大词拓展 | 自然搜索排名分布、广告依赖度（广告位占比）、PPC 建议竞价、高转化长尾词 |
| **ASIN销售趋势** | 历史月度销量与变体贡献 | 爆款放量节点、子变体销售占比、近期是否存在异常断货或暴跌 |
| **ASIN运营趋势** | Keepa 价格与 BSR 曲线 | 历史价格是否频繁大幅降价打价格战、BSR 稳定性、优惠券依赖度 |
